# SAMP PC — Download APK

Engine Wine/Box64 (Winlator) + frontend SA-MP digabung jadi **satu APK**.
Data game (GTA:SA + SA-MP) **tidak** ikut di sini — app mengunduhnya sendiri dari
link Google Drive milikmu, lalu mengekstraknya ke SD card / memori internal.

## Unduh

| File | Ukuran | Untuk |
|---|---|---|
| [samp-pc-v1.1.0-merged-debug.apk](../../releases/latest) | 546 MB | **install ini** — sudah ada engine-nya |
| samp-pc-v1.1.0-frontend-debug.apk | 75 KB | cuma UI, buat ngetes tampilan |

## Syarat

- Android 9+ (arm64), RAM 3 GB+ (4 GB lebih aman)
- Ruang kosong ±2 GB untuk APK + data tier EXTREME

## Cara pakai

1. Convert paket RAR di PC → ZIP (lihat `PANDUAN-PC.md` di repo source).
2. Upload ZIP ke Google Drive, Share → *Anyone with the link*.
3. Install APK di HP, buka app.
4. Tempel link Drive → **Unduh paket** → tunggu → **Jalankan SA-MP**.

## Catatan

- Debug-signed: wajar kalau Play Protect minta konfirmasi "install anyway".
- Helio G36 / RAM 2–3 GB: main di 640×360 tier SAFETY; realistis 5–12 fps.
